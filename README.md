## Prerequisites

- neovim
- hyprland
- hypridle
- hyprlodk
- hyprpaper
- waybar
- wlogout
- wofi
- yazi
- kitty
- dunst
- fish
- micro
- tmux

## Installation

```bash
git clone --recurse-submodules https://github.com/Kingcxp/.config.git
rm -rf .config/.git/
mv .config/* ~/.config/
mv ~/.config/.tmux.conf ~/.tmux.conf
```

You need to remove necessary files from the config folder before the installation.
